# Contributing

Thank you for improving tinyslug. Open an issue before a large architectural change so design work is not duplicated.

1. Follow the setup steps in `README.md`.
2. Add or update tests for observable behavior.
3. Run `mise exec -- bin/ci`.
4. Keep commits focused and explain intent in commit messages.

Never commit credentials, production data, visitor identifiers, or recorded third-party responses. By contributing, you agree that your work is licensed under the MIT License.
